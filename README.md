### 👨‍💻 About Me

I am an **Embedded Systems & Software Engineer** focusing on high-integrity systems, state estimation, and safety-critical architectures. My work emphasizes verifiability, deterministic execution, and adherence to rigorous aerospace and automotive development methodologies.

---

### 🚀 Featured Project

#### [Attitude Estimator (EKF) — DO-178C-Inspired Software Lifecycle](https://github.com/TomasUPV/attitude-estimator-cpp)
* **Scope**: 6-DOF IMU attitude estimation using an Extended Kalman Filter, following the lifecycle disciplines of **DO-178C** and **MISRA C++** standards.
* **Engineering**: Pure Hamilton quaternion kinematics, static memory footprint (zero runtime heap), and strict bidirectional traceability from requirements to GoogleTest verification.

👉 **[Explore repository & certification artifacts](https://github.com/TomasUPV/attitude-estimator-cpp)**
